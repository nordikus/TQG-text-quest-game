# Chronicle of Fate

A first-person adventure for Game Off 2026. Explore a forest and its castle, piece together what happened, and see how your choices change the world.

## Play on Windows

Download the Windows x64 ZIP from [GitHub Releases](https://github.com/nordikus/TQG-text-quest-game/releases/latest). Extract the archive and run `TQG.exe`. Keep `TQG.pck` in the same folder.

**Controls** — WASD to move, mouse to look, Space to jump, E to interact, Tab to open the inventory, and Esc to pause or save.

Open the source project in Godot 4.7.2 to run it from the editor. See [Credits](CREDITS.md) for asset sources and licenses.
